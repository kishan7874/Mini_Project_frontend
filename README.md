ASP.NET Web Forms / .NET Framework 4.8 mini project.

## Run
1. Extract the ZIP.
2. Open Visual Studio 2022.
3. File > Open > Web Site.
4. Select this folder.
5. Set Default.aspx as the Start Page.
6. Press Ctrl+F5.

## Features
Home, categories, product search, product catalogue, 12 products with consistent prices, local SVG product artwork, session cart, quantity controls, checkout validation, demo payment choices, demo login, order confirmation, responsive UI.
